## Features

<CardGrid>
	<Card title="Home Inventory" icon="asset">
	    Catalog the things you own, from appliances and tools to books, games, and furniture, and keep their details in one place.
	</Card>
	<Card title="Smart Import" icon="import">
	    Import assets instantly from Google Books, TMDB, and BoardGameGeek with automatic metadata, cover images, and custom attributes.
	</Card>
	<Card title="Rooms, Shelves, and Boxes" icon="hierarchical">
	    Build nested locations that mirror your home, so you can record exactly where an item lives and find it again later.
	</Card>
	<Card title="Warranty Tracking" icon="warranty">
	    Keep purchase details and warranty dates beside each item, with a clear view of warranties that need attention.
	</Card>
	<Card title="Custom Attributes" icon="attributes">
	    Give each category the fields it needs, such as serial number, author, size, model, or purchase date.
	</Card>
	<Card title="File Attachments" icon="attachments">
	    Keep receipts, manuals, photos, and other documents with the item they belong to.
	</Card>
	<Card title="Full-Text Search" icon="search">
	    Search your inventory and filter it by category, location, condition, or collection.
	</Card>
	<Card title="Collections" icon="collections">
	    Group related belongings—such as a book series, game collection, or moving box—without changing where they are stored.
	</Card>
	<Card title="Self-Hosted" icon="selfhosted">
	    Keep control of your household data. Run Attic with Docker on your own server, with no required cloud service or subscription.
	</Card>
	<Card title="Single Sign-On (SSO)" icon="sso">
	    Integrate with your existing identity provider using OIDC/OpenID Connect. Works seamlessly with PocketID, Keycloak and other providers.
	</Card>
	<Card title="REST API" icon="api">
        Use the documented API to build integrations or automate updates to your home inventory.
	</Card>
	<Card title="Condition Tracking" icon="tracking">
	    Record whether belongings are new, used, damaged, or in any custom condition you define.
	</Card>
	<Card title="Plugin System" icon="plugin">
	    Add new import sources without writing code. Plugins automatically create categories, attributes, and fetch cover images.
	</Card>
	<Card title="Dark Mode" icon="darkmode">
	    Use a responsive interface designed for checking your inventory from a computer, tablet, or phone.
	</Card>
</CardGrid>
